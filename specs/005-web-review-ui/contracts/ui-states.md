# Контракт состояний интерфейса

**Дата**: 2026-09-04. Основание: [спецификация](../spec.md), [openapi.yaml](../../../contracts/review-platform/v1/openapi.yaml).

Документ фиксирует, какое состояние интерфейса соответствует каждому состоянию контракта. Ни одно состояние не приводит к пустому экрану (FR-013). Тексты в таблицах — назначение сообщения, а не готовые формулировки.

## Готовность документа к запуску

Источник: `Document.extraction_state`. Требование: FR-040.

| `extraction_state` | Запуск | Что показывает интерфейс |
| --- | --- | --- |
| `pending` | недоступен | документ ещё готовится, ожидание извлечения |
| `completed` | доступен | документ готов |
| `partial` | доступен | предупреждение: часть текста не прочитана и не будет проверена |
| `failed` | недоступен | причина запрета и предложение загрузить документ в другом виде |

## Состояния запуска

Источник: `ReviewRun.state`, `progress`, `error`, `report_available`. Требования: FR-013, FR-014, FR-015, FR-039.

| `state` | Опрос | Переход к отчёту | Состояние интерфейса |
| --- | --- | --- | --- |
| `queued` | активен | нет | в очереди, показ `progress.message` |
| `preparing` | активен | нет | подготовка источников |
| `reviewing` | активен | нет | идёт проверка |
| `validating` | активен | нет | проверка результата |
| `completed` | выключен | да | успешно завершён |
| `failed` | выключен | нет | причина по `error.code`, признак `retryable`, отчёт не опубликован |
| `cancelled` | выключен | нет | отменён, отчёта нет |

Наложенное состояние интерфейса: если `state` и `progress` не менялись 15 минут, к любому нетерминальному состоянию добавляется предупреждение «идёт дольше обычного» с длительностью запуска и подсказкой вернуться позже. Предупреждение не подменяет `state` и не выключает опрос (FR-039, SC-013).

Коды `error.code`, для каждого из которых нужен собственный человекочитаемый текст: `invalid_document`, `unsupported_document`, `extraction_failed`, `context_limit`, `model_unavailable`, `model_output_invalid`, `validation_failed`, `cancelled`, `internal_error`.

## Состояния отчёта

Источник: `ReviewReport.coverage.status`, `findings`, `provenance.sources`. Требования: FR-019, FR-022, FR-023.

| Ситуация | Состояние интерфейса |
| --- | --- |
| `coverage.status: complete`, есть замечания | обычный разбор: сводка, список замечаний, ограничения |
| `coverage.status: complete`, `findings` пуст | явное сообщение «замечаний не найдено» вместе с охватом и ограничениями |
| `coverage.status: partial` | заметный признак неполного результата, перечень `gaps` с причинами, статусы источников |
| Источник со статусом `partial` или `unavailable` | источник показан с его статусом и диагностикой; из перечня не исчезает |
| Отчёт запрошен у незавершённого запуска (`409`) | объяснение, что отчёта нет, и возврат к состоянию запуска |

## Состояния замечания и решения

Источник: `HumanDecision.status`, `revision`. Требования: FR-024 — FR-028.

| `status` | Состояние интерфейса | Обязательные поля при сохранении |
| --- | --- | --- |
| `unreviewed` | не рассмотрено | `reason` и `resolution` отправляются как `null` |
| `confirmed` | подтверждено | `reason` обязательно |
| `rejected` | отклонено | `reason` обязательно |
| `needs_context` | нужен контекст | `reason` обязательно |

Состояния процесса сохранения:

| Ситуация | Состояние интерфейса |
| --- | --- |
| Сохранение выполняется | форма заблокирована на время запроса, ввод сохранён |
| `200` | показ сохранённого решения с автором и временем, обновление счётчика разобранных замечаний |
| `409 revision_conflict` | состояние конфликта: актуальное значение перезагружено и показано рядом с введённым, ввод не потерян, повтор одним действием с новой ревизией |
| `400` | сообщение о невалидном вводе с указанием поля из `Problem.errors` |

## Состояния диалога

Источник: `FindingDialogue.state`, `can_send_message`, `blocked_reason`, `turns[].state`. Требования: FR-030 — FR-036.

| `blocked_reason` | Что показывает интерфейс |
| --- | --- |
| `null` при `can_send_message: true` | отправка доступна |
| `generation_in_progress` | предыдущий ход ещё не завершён |
| `turn_limit_reached` | исчерпан лимит ходов политики диалога |
| `human_decision_recorded` | решение по замечанию сохранено, диалог закрыт |
| `dialogue_not_supported` | диалог для этого замечания не поддерживается |
| `model_unavailable` | профиль модели временно недоступен |

Состояния хода:

| `turns[].state` | Опрос | Состояние интерфейса |
| --- | --- | --- |
| `queued` | активен | ход принят, ответ готовится |
| `generating` | активен | ответ готовится |
| `completed` | выключен | текст ответа, `action`, привязки, предложенная резолюция при наличии |
| `failed` | выключен | `error.code`, при `retryable: true` — повтор без повторного ввода вопроса |

Инвариант: одновременно активен не более одного хода замечания. Доступность отправки берётся только из `can_send_message`; клиент её не вычисляет (SC-008, R-08).

## Предложенная резолюция

Требование: FR-029, SC-007, принцип V.

| Шаг | Действие | Что происходит |
| --- | --- | --- |
| 1 | Ответ содержит `proposed_resolution` | предложение показано отдельно от решения, решение остаётся `unreviewed` |
| 2 | Аналитик выбирает «использовать предложение» | `proposed_resolution.text` подставляется в поле `resolution` формы решения; ничего не сохраняется |
| 3 | Аналитик сохраняет решение | выполняется `PUT .../decision` с выбранным статусом и обоснованием |

Пропуск шага 2 или 3 оставляет решение нерассмотренным. Автоматического применения нет ни при каком условии.

## Сетевые и общие состояния

| Ситуация | Состояние интерфейса |
| --- | --- |
| Загрузка данных экрана | видимый индикатор загрузки, а не пустая область |
| Связь потеряна при опросе | сообщение, что состояние не обновляется; опрос возобновляется автоматически, контекст экрана сохраняется |
| `404` по любому идентификатору | «не найдено», без упоминания входа, прав и доступа (FR-003) |
| Любой `Problem`-ответ | текст выбирается по `Problem.code`, а не по серверной строке; `request_id` доступен для диагностики (R-11) |

Все перечисленные состояния различимы не только цветом: каждое сопровождается текстом или знаком (FR-042).
