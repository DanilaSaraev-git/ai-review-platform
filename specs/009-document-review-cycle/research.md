# Research: основания технических решений

## Existing behavior

Повторный create-run уже принимает сохранённый document_id. Upload создаёт неизменяемую DocumentVersion; семейства нет. HumanDecision и dialogue хранятся отдельно от canonical report. История UI сейчас организована по запускам.

Проверено на исходниках baseline 6ce14c1: `packages/review-runtime/src/review_runtime/postgres/platform.py`, `packages/review-core/src/review_core/application/platform.py`, `apps/api/src/review_api/routes/reviews.py`, `contracts/review-platform/v1/openapi.yaml`.

## Decisions

- **Семейство поверх версии.** Сохранить document_id как ID исходника, ввести отдельный family ID. Это совместимо со старыми ссылками; переименование document_id ломало бы отчёты и consumers.
- **Отдельное состояние цикла.** Опубликованный отчёт неизменяем. Связи и подтверждения живут отдельно с историей и optimistic revision.
- **Сквозная история проблемы.** Сохранять замечания, исчезнувшие из новых отчётов, чтобы распознать возврат через несколько версий. Ручная связь только один-к-одному.
- **Консервативный перенос.** Совпадение точных смысловых полей замечания плюс источников и условий. При изменении хотя бы одного источника и недоказанной локальности изменения — пересмотр. Модель не вызывается дополнительно.
- **Фиксированный baseline.** Последняя опубликованная проверка семьи на момент создания запуска. Историческим данным не приписывать несуществующие семейства по имени.
- **PDF из серверного снимка.** Согласованно читать отчёт, решения и цикл; после чтения render не держит долгую транзакцию. Это исключает разъехавшиеся счётчики из клиентских кэшей.
- **ReportLab.** Поддерживает разбиение длинных абзацев и экранируемую разметку; входной текст всегда экранировать. [Официальная документация Paragraph](https://docs.reportlab.com/reportlab/userguide/ch6_paragraphs/), просмотрено 2026-09-06.
- **DejaVu Sans.** Кириллический шрифт поставляется вместе с runtime и лицензией; [лицензия проекта](https://github.com/dejavu-fonts/dejavu-fonts/blob/master/LICENSE). Системные proprietary fonts не использовать.

## Validation limits

Нет набора реальных пар документов с экспертной разметкой. Синтетические тесты подтверждают инварианты и воспроизводимость, но не точность семантического сопоставления и не экономию времени.
