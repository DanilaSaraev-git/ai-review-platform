После уточнения поведения `needs_context` и отдельного источника вложения повторно прошли 7 затронутых интеграционных и контрактных тестов. Проверены memory и изолированный PostgreSQL, неизменяемость отчёта, сохранение завершения, его отмена изменением решения, передача вложенного источника подготовке диалога и отказ для недоступного документа.
- Web: 27 целевых проверок в отдельных запусках Vitest — решения, первый вопрос диалога, эффективные решения, рабочие статусы, сопоставление, прежние ссылки, загрузка новой версии и отправка уточнений. - TypeScript, ESLint, сборки web/API, `git diff --check` прошли. Симлинки `CLAUDE.md → AGENTS.md` сохранены.
- Локальные контейнеры API и proxy обновлены на `http://localhost:18109`, прежние данные сохранены. Readiness подтверждает БД, схему, seed и хранилище артефактов.
- В браузере проверены единый список и переход в результат, подсказка следующего действия, вкладки замечания, вопрос из отчёта первым сообщением, диалог новой версии с файлами контекста и отключённым запуском без файла, панель истории. Эти проверки не изменяли решения и не запускали модель.

## Отмена запуска проверки

Дополнение от 2026-09-06, ветка `codex/cancel-review`, по поручению пользователя добавить отмену и соответствующий статус.

- На экране активного запуска добавлена кнопка «Отменить проверку» через существующий сгенерированный клиент `cancelReviewRun`. Контракт, сервер и схема данных не изменены.
- Кнопка доступна в очереди, при подготовке, анализе и валидации. Во время запроса показано «Отменяем проверку…», повторное нажатие заблокировано; при отсутствии сети действие недоступно. Статус «Отменена» появляется только после серверного подтверждения. В фиксированном деморежиме действие не показывается.
- Ошибка запроса позволяет обновить состояние или повторить попытку. Конфликт `run_terminal` обновляет фактический результат; уже опубликованный отчёт остаётся доступен. Старый ответ фонового опроса не перезаписывает подтверждённую отмену. Обновляются кэши списка и истории.
- Vitest: 37 целевых тестов экрана запуска, отмены и определения зависания прошли; в том числе 12 тестов отмены, покрывающих состояния, потерю связи, подтверждение, повтор после ошибки, гонку с завершением и поздний ответ опроса.
- PostgreSQL/API: два существующих теста `test_review_cancellation.py` и `test_cancel_during_model_call_wins_over_late_result` прошли. Отмена во время модельного вызова сохраняется, поздний результат не публикуется; отмена готового отчёта отклоняется.
- Playwright: сценарий `cancel-review.spec.ts` прошёл в Chromium на синтетическом MSW-наборе: действие → статус → перезагрузка → история → список. Снимки до и после проверены визуально. TypeScript, ESLint, web build и `git diff --check` прошли.

Границы: модельный провайдер заменён тестовой заглушкой; отмена уже отправленного запроса на стороне внешнего провайдера не гарантируется существующим API. Его поздний результат не публикуется. Изменения находятся в отдельном локальном checkout; прежний стенд и удалённый сервер не обновлялись.

## Отдельная ветка деморежима

`codex/demo-review-cycle` создана от main после слияния `6ee9afc`. Деморежим доступен на `http://localhost:18109/demo/`; серверные API и хранилище не изменены. Демо использует поставляемые синтетические данные и sessionStorage, а неизвестные API-запросы возвращают локальную ошибку.

Прошли TypeScript, ESLint, production-сборки обычного интерфейса и `/demo/`, два целевых Vitest-теста и два Playwright-теста production-демо. Покрыты решения, новый файл версии 2, запрет преждевременного завершения, подтверждение исправлений, завершение, восстановление после обновления, история версий, открытый диалог при `needs_context`, идентификаторы вложений и блокировка неподдерживаемых запросов. Playwright подтвердил отсутствие ответов живого API и работу без приватных runtime-файлов.

Дополнительно вручную в браузере localhost пройден путь: новая проверка с демофайлом → имитация анализа → вопрос и готовый ответ → два решения → демоверсия с правками → два подтверждения исправлений → явное завершение. Печатный экспорт реализован через браузерный диалог сохранения PDF; само сохранение файла системным диалогом не проверялось. Удалённая выкладка и вызовы модели не выполнялись.
