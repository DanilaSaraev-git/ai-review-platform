# Единая проверка — согласованный интерфейс

Основание: утверждённый локальный макет и последующие правки пользователя 2026-09-06. Реализация разрешена явно; выкладка на удалённый сервер не разрешена.

- В меню «Новая проверка» и «Проверки». Одна строка на семейство ТЗ; открывается последний запуск.
- Рабочий экран сохраняет исходник слева. История — боковая панель с версиями и запусками, загрузка новой версии — диалог с новым файлом, наследованием параметров и контекста. Повтор без выбора файла исключён из интерфейса.
- Статус указывает действие: разбор, уточнения, новая версия, подтверждение исчезнувших замечаний, явное завершение. needs_context остаётся открытым, confirmed называется «Принято к доработке». Частичный анализ, неопределённое сопоставление и недоступные данные блокируют успешное завершение.
- Изменения помечены у замечаний; исчезнувшие сгруппированы для проверки исправлений. Старые результаты доступны по прежним ссылкам и отмечены как предыдущие.
- Сохраняется прежняя информативная карточка: описание, цитата, основание, вопрос, подробности. Вкладки «Решение» и «Диалог». После сохранения — следующее замечание; резолюция исключена из интерфейса. Обоснование остаётся обязательным согласно контракту.
- Первое сообщение диалога — clarification_question опубликованного замечания, без дополнительного вызова модели. Файлы прикрепляются к диалогу и входят в контекст модели; чужие документы запрещены сервером.
- PDF выгружается с текущими решениями. Завершение сохраняется отдельно от неизменяемого отчёта; новый запуск продолжает цикл.

Проверка: синтетический цикл v1→решения→v2→подтверждение исправлений→явное завершение, история, needs_context, вкладки, файлы, сохранение после обновления. Никаких платных модельных прогонов.
