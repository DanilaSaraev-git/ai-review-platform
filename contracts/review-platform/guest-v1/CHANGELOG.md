# Changelog: Guest API

## 1.0.0 — 2026-09-06

- Введён отдельный опциональный контракт гостевого deployment с bootstrap, создающим или восстанавливающим постоянную браузерную сессию.
- Добавлена cookie security scheme `GuestSession` для `review_guest`, ошибки `401/403` и граница доступа к workspace.
- Зафиксированы `413/503` при ограничениях хранения; исходные предметные DTO, пути `/v1` и skill JSON сохранены из trusted-v1 baseline.
- Документированы 30-дневное продление сессии, сохранение данных после её истечения, приватность подготовленного демо и отказ gateway при несовпадении режима API.

Это версия контракта. Она не подтверждает успешный production rollout; фактические проверки ведутся в [evidence среза 008](../../../specs/008-guest-access/evidence.md).
